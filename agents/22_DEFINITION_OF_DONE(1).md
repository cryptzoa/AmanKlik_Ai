# 22 — Definition of Done

Project is not done until every P0 is true.

## Repository
- [ ] AGENTS followed
- [ ] STATE current
- [ ] no secrets
- [ ] lockfile
- [ ] setup README
- [ ] understandable Git history

## Quality
- [ ] lint
- [ ] typecheck
- [ ] unit
- [ ] P0 E2E
- [ ] build
- [ ] no fatal console errors

## Landing
- [ ] distinctive
- [ ] responsive
- [ ] CTA
- [ ] no forced intro
- [ ] reduced motion
- [ ] touch/mobile

## Text
- [ ] validation
- [ ] deterministic rules
- [ ] live AI
- [ ] structured validation
- [ ] code-computed score
- [ ] persistence
- [ ] degraded path
- [ ] redaction

## Screenshot
- [ ] magic-byte image validation
- [ ] max 5 MB
- [ ] Sharp preprocess
- [ ] no persistence
- [ ] Gemini multimodal
- [ ] schema validation
- [ ] recoverable provider error

## URL
- [ ] http/https
- [ ] static parsing
- [ ] tldts
- [ ] registrable domain shown
- [ ] structural signals
- [ ] **zero target fetch**

## Result
- [ ] 0–100
- [ ] textual level
- [ ] no guaranteed verdict
- [ ] evidence

- [ ] actions
- [ ] uncertainty/disclaimer
- [ ] URL anatomy when relevant
- [ ] analysis mode

- [ ] anonymous secure cookie
- [ ] ownership enforced
- [ ] history

## Simulator
- [ ] >=3 scenarios
- [ ] branches
- [ ] deterministic completion
- [ ] AI optional
- [ ] no live scam generation dependency
