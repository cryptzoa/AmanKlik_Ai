## Perlakukan lampiran aplikasi sebagai risiko perangkat

Pesan tentang paket, undangan, tagihan, atau layanan publik dapat menyamarkan aplikasi Android berbahaya sebagai dokumen. Jangan memasang APK dari percakapan atau memberi izin akses hanya karena nama dan ikon filenya terlihat meyakinkan.

Jika file sudah dipasang, putuskan interaksi dengan pengirim, hapus izin aplikasi yang mencurigakan dari perangkat tepercaya, amankan akun finansial melalui aplikasi resmi, dan periksa aktivitas transaksi. Simpan pesan serta detail kejadian untuk pelaporan tanpa meneruskan file berbahaya kepada orang lain.
